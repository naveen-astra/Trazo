# replayFixtures/

`sample-divergence-report.json` is the exact JSON shape `trazo verify
<run_id> --json` prints (`sdk/src/trazo/cli/replay.py`'s
`_report_summary`/`_divergence_summary`) — generated by constructing a
real `ReplayReport` in Python (two matched boundary calls, one state
mismatch, one divergence) and serializing it with the CLI's own
functions, not hand-typed. There is no live endpoint that produces a
divergence report today (replay sessions run inside the SDK's Python
process, not the browser, and nothing currently exposes "trigger a
replay" over HTTP) — this fixture is what lets `DivergenceReport`
(TRZ-P6-07) be built and reviewed against a real shape ahead of that
wiring existing.
